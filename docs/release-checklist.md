# 微信小程序发布检查表

- [ ] 使用已登记的 AppID 替换开发配置中的占位值；AppSecret 只通过服务器端密钥管理注入，不进入小程序包或源码。
- [ ] 在小程序后台配置并校验 HTTPS request 合法域名及 WSS socket 合法域名。
- [ ] 确认棋牌类目、运营资质及当前主体是否符合微信平台审核要求。
- [ ] 确认隐私政策披露微信登录、openid 处理目的、保存范围和用户权利。
- [ ] 微信开发者工具编译检查完成，并在真机预览及体验版验证静默登录、房间邀请和异常提示。
- [ ] 后端 HTTPS 微信登录、默认房/邀请进房 API、牌局动作/快照和授权过滤均部署并通过集成验证。
- [ ] 验证弱网、后台切换、WSS 重连与同步方案；当前通知 WebSocket 不包含牌局快照补发。
- [ ] 确认正式网关使用 HTTPS/WSS，服务端密钥从环境变量/密钥管理注入，不在客户端保存。
