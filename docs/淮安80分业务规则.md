# 淮安80分 业务规则（终稿）

> 版本：v1.5（新增自然级规则） · 本文档为业务规则定义，供游戏开发/落地实现方直接使用，无歧义、可执行。

---

## 1 游戏概述与目标

淮安80分是一款**四人两两配合**、以"吃分升级"为核心的扑克牌游戏。

- 四人分为两组，座位相对的两人为一家，互为**对家**。
- 一方担任**庄家**（庄家方 / 打家），另一方为**抓分方**（闲家）。
- 使用两副完整扑克牌，通过**暗扣级牌定主（含反主）→ 扣底 → 出牌 → 抓分**完成一局；抓分方累计抓满 **80 分**即可上台换庄。
- 双方从级牌 **2** 开始逐级向 **A** 推进，先完成从 2 打到 A（"转一圈"）者为胜方。

**庄家方目标**：利用扣底权与首轮出牌权，尽量不让抓分方得分，守住庄位并逐级上升。
**抓分方目标**：尽量抓取 5、10、K 分牌，抓够 80 分上台换庄，分数越高升级越快。

## 3 玩家角色

- **庄家**：拥有**扣底权**和**首轮首先出牌权**，利用特权尽量不让对手得分。
- **对家 / 庄家方**：固定对家，座位相对的两人互为对家并组成一家；庄家与其对家组成庄家方（打家）。
- **抓分方（闲家）**：与庄家方相对的另一组对家，目标是抓取分牌、凑够 80 分上台。

---

## 4 级牌与主牌

### 4.1 级牌
- 从打 **2** 开始，逐级上升（2 → 3 → … → K → A）。
- 当前庄家方所打的级别即为级牌，级牌为当前级别所有花色的牌。
- 升级到 K 则 K 成为级牌，依此类推直至 A。

### 4.2 主牌构成
主牌由三部分构成：**大小王、级牌、主花色牌**。

### 4.3 牌力层级（红五特色启用）
主牌由大到小依次为：

| 级别 | 牌 |
|---|---|
| 1（最大） | **红桃5（红五）** |
| 2 | 大王 |
| 3 | 小王 |
| 4 | 主花色级牌（如打 2 时的主 2） |
| 5 | 其他花色级牌（副 2） |
| 6 | 主花色牌 A、K、Q、J、10…2 |
| 7（最小） | 副牌 A、K、Q、J、10…2 |

> 注：本规则**不引入"参谋"（数字 3）机制**，仅以红桃 5 作为全场最大主牌。红五（红桃 5）被对手抓住**不额外扣分**，按普通分牌（5 分）计分。

## 5 定庄与定主

> ⚠️ **本章为自定义规则（优先级最高）**：定主采用"暗扣级牌定主 + 反主（暗反）"体系，取代原有的抢亮定庄。

### 5.1 抢定者（定主）

- **时机**：发牌阶段。
- **动作**：任意玩家可选择用**一张级牌暗扣定主**，其他玩家**看不到**该牌。该玩家成为**抢定者**，其所暗扣级牌的花色定为主花色。
- 抢定者一经选定，即拥有**回头望**特权（见 5.4）。

### 5.2 反主流程（暗反）

- **时机**：庄家扣完底牌后进入反主阶段。
- **起始轮询**：从**庄家的下家**开始轮询是否反主；**若首次轮询到的下家正是抢定者，则跳过该玩家**。
- **反主用牌**：必须用 **对级牌 / 对小王 / 对大王 / 对红五** 中的一种反主。
- **反主动作**：反主者可取 8 张底牌再扣 8 张（换底牌）；扣完后**从当前扣主玩家向下继续轮询**。
- **对子大小**：反主的对子**必须比上一家大**，从大到小为：**红五对 > 大王对 > 小王对 > 级牌对**（级牌花色不分大小）。
- **抢定者参与**：抢定者首轮被跳过后，后续轮询到他时，**既可用其他对子正常反主，也可在有人反主后选回头望**（两个权利都保留）。

### 5.3 反主结束

从庄家开始向下**按座位顺序逐个轮询，反主者扣底后从他下家续问**，**累计连续三个玩家说不反主**即反主阶段结束。

### 5.4 回头望（抢定者特权）

- 当**有人反主**且轮询到抢定者时，抢定者可选择**用当初抢定的级牌进行最终定主**，视为**反主阶段最大**，并**过一轮底牌**。
- 回头望之前，抢定者也可用其他对子反主，**仍保留回头望特权**。

### 5.5 暗反违规惩罚

- 反主全程为**暗反**（暗扣，其他玩家看不到），由**系统判定**是否违规。
- **违规情形**：反主对子**小于上一家**（即违反 5.2 的对子大小规则）。
- **惩罚**：违规者所在方**直接输掉该局**——**违规方输局**。
  - 若违规者是**闲家** → 闲家按 **0 分**算（庄家方大胜升级）；
  - 若违规者是**庄家** → 闲家按 **200 分**算（闲家方大幅升级）。

### 5.6 红五反主

- **一对红五**可搭配任意花色**反任意主**：
  - 搭配**级牌 / 大小王** → 视为**无主**；
  - 搭配**其他花色** → 视为**该花色主**。
- **持牌要求**：玩家必须持有**对红五**；但**暗反时只需暗扣一张红五 + 任意一张牌**即可。

### 5.7 无人定主处理（保留原规则）

发牌结束仍无人定主时：
1. 取底牌 8 张中**最上面一张**的花色定为主牌花色；
2. 若该张牌为**级牌、大小王或红五（红桃5）**，则按**"无主"**处理（此时只有大小王和级牌为主牌）。

## 6 牌型

| 牌型 | 定义 |
|---|---|
| 单张 | 任意单张牌 |
| 对子 | 两张相同点数、相同花色的牌 |
| 拖拉机 | 同花色的相邻两对或以上的连对；级牌不能与同花色副牌构成拖拉机 |
| 甩牌 | 同花色的大牌连出，须保证所甩牌型为当前最大，否则不能甩出 |
| **510k（自定义）** | 同花色 **5、10、K** 三张组成的组合牌型，可作一手甩牌打出，属该花色最大；**主牌 510k 可盖过副牌 510k** |

## 7 底牌与扣底

### 7.1 扣底（埋牌）
定主后，8 张底牌归庄家所有；庄家从手中选出自认为不需要的 8 张牌替换进底牌，此过程称为扣底。底牌中的分牌需防止被抓分方抄底。

### 7.2 抄底与倍数（标准规则）
一局结束时，若**最后一轮由抓分方获胜**，称为抄底，底牌中的分牌按最后一轮最大牌型对应的倍数加倍计入抓分方得分：

| 最后一轮最大牌型 | 抄底倍数 |
|---|---|
| 单张 | ×2 |
| 一对 | ×4 |
| 两对 | ×8 |
| 拖拉机（每多一对再加倍） | ×8 起，依此类推 |

若最后一轮由庄家方获胜，底牌中的分牌归庄家方所有，**不翻倍**。

### 7.3 翻盘机制（自定义规则）

当**庄家所打的级牌为 J 或 A**，且**抓分方用该级牌抄底**时，触发翻盘机制。翻盘为**叠加结算**：先按 7.2 抄底倍数正常算分，再额外对庄家级数做降级处罚。

| 庄家所打级牌 | 闲家抄底牌型 | 庄家级数处罚 | 交换庄权 |
|---|---|---|---|
| **J** | 单 J | 强制降为 **3** | 按 80 分标准判定（闲家≥80 换庄，<80 不换） |
| **J** | 对 J | 强制降为 **2** | 按 80 分标准判定（闲家≥80 换庄，<80 不换） |
| **A** | 单 A | 强制降为 **J** | **强制交换庄权** |
| **A** | 对 A | 强制降为 **2** | **强制交换庄权** |

**翻盘机制细则**：
- **打 J 翻盘**：闲家用 J 抄底（单 J 或对 J），庄家级数**强制**降为 3 或 2——即使闲家得分 ≤70 不够上台，庄家仍被强制降级；但**是否交换庄权看分数**（闲家≥80 换庄，否则不换，庄家降级后继续坐庄）。
- **打 A 翻盘**：闲家用 A 抄底时，**优先看总分**——若总分 **≤75**，按打 A 规则判定（庄家获胜）；否则触发翻盘：单 A → 庄家级数降为 **J**，对 A → 降为 **2**，并**强制交换庄权**。
- 翻盘机制仅在庄家所打级牌为 **J 或 A** 时触发；打其他级牌不触发。
- 翻盘降级与抄底倍数计分**叠加**进行，互不影响。

## 8 出牌规则

- **出牌顺序**：第一轮由庄家先出牌；之后每一轮由上一轮牌最大的玩家先出牌。
- **跟牌与毙牌**：非首家出牌方必须先跟首家所出的花色；无该花色牌时，可用主牌毙（须同牌型同数量），或垫其他花色牌。

### 8.1 510k 甩牌（自定义规则）

- **触发**：仅当某玩家为**首家（主动出牌）**时，可将手中**同花色 5、10、K** 三张作为一手甩牌打出。
- **牌力**：510k 属该花色的**最大组合**；**主牌 510k 可盖过副牌 510k**。
- **带牌结算**：510k 可与其他牌一起甩出。结算时，**510k 三张作为整体**判断大小（该整体为最大），**其余带出牌**仍须各自单独满足甩牌最大条件（即每张/每组都须是当前最大才能一并甩出）。
- **带牌限制（仅主 510k）**：**主牌 510k 不可以再带其他主牌**一起甩出；但可带副牌甩出。

### 8.2 抽筋（自定义规则）

- **触发**：当某玩家以**主牌 510k** 甩出时，触发抽筋。
- **效果**：**其他玩家必须出手中最大的三张主牌**（若某玩家主牌不足三张，则用任意副牌补齐）；称此动作为"**抽筋**"——抽出其他玩家 3 张最大主牌。
- **范围**：抽筋**仅在主 510k 甩出时**触发；甩副牌 510k 时，其他玩家按正常跟牌/毙牌规则应对。
- **主 510k 与副牌组合**：主 510k 甩出时若带副牌，主牌部分的抽筋照常触发，带出的副牌部分按普通甩牌跟牌规则处理。

### 8.3 上天入地（自定义规则）

- **触发**：某玩家以 **510k 作为最后一手牌**主动打出、且该手为最大（整局随之结束），该玩家所在方直接获得**下一局庄权**。
- **判定"最后一手"**：指该玩家出完这手 510k 后**手中无牌、整局结束**，且该手 510k 为最大。
- **等级跳转**：上天方下一局**打 A**，对手方下一局**打 2**（跨过中间所有等级），随后按常规推进。此机制**无视得分结算与必打级（2/J/A）限制**。
- **反压转移**：若**副牌 510k** 被对手**主牌 510k** 反压，则视为**反压方上天入地**，由反压方获得下一局庄权。

### 8.4 春天（自定义规则）

- **定义**：在**第一局**就达成"上天入地"（即该局内一方以 510k 作为最后一手主动打出且最大，直接获得下一局庄权并**打 A 对 2**），随后在**打 A** 的那一局中**获胜**（对手 ≤75），即**两把结束**（共打两局）分出胜负，称为"**春天**"。
- **判定要点**：
  - 必须是**第一局**就上天入地（打 A 对 2）；
  - 第二局（打 A）获胜，全程**只打两局**结束。
- **积分影响**：春天场景下，级差按 **A:2（级差 12）** 结算，且按 **"两把结束"** 档位计算——积分 = 级差 × 40 = **480**（再乘大厅系数，见设计文档积分规则）。

## 9 胜负判定与升级

每局结束统计**抓分方（闲家）**的得分。得分只能为 **5 的倍数**（因分牌为 5、10、K）。按 **每 10 分一档、以 80 为界**判定升级、下庄或换庄。

> ⚠️ **必打级机制（自定义规则，优先级最高）**：等级 **2、J、A** 为"必打级"，是升级推进的关卡。任何一方推进到必打级时，必须在该级上先打一局，**不能通过普通得分直接跳越**。详见 9.2 与 9.3。

### 9.1 一般等级升级结算表（非必打级，或必打级上的具体结果见 9.3）

| 闲家得分 | 结果 |
|---|---|
| 0 | 庄家方升 8 级 |
| 5、10 | 庄家方升 7 级 |
| 15、20 | 庄家方升 6 级 |
| 25、30 | 庄家方升 5 级 |
| 35、40 | 庄家方升 4 级 |
| 45、50 | 庄家方升 3 级 |
| 55、60 | 庄家方升 2 级 |
| 65、70 | 庄家方升 1 级 |
| **75** | **不升级、不换庄（庄家留级续坐）** |
| **80、85** | **换庄，双方不升级** |
| 90、95 | 闲家升 1 级 |
| 100、105 | 闲家升 2 级 |
| 110、115 | 闲家升 3 级 |
| 120、125 | 闲家升 4 级 |
| 130、135 | 闲家升 5 级 |
| 140、145 | 闲家升 6 级 |
| 150、155 | 闲家升 7 级 |
| 160、165 | 闲家升 8 级 |
| 170、175 | 闲家升 9 级 |
| 180、185 | 闲家升 10 级 |
| 190、195 | 闲家升 11 级 |
| 200 | 闲家升 12 级 |

> 换算规则（供实现）：以 80 分为界，每 10 分一档向下取整。闲家得分 < 80 时庄家方升级、= 75 时留级；闲家得分 ≥ 80 时换庄，> 80 后每多 10 分闲家再升 1 级。

### 9.2 必打级机制（等级 2、J、A）

**定义**：等级 **2、J、A** 为"必打级"，作为升级推进的关卡。

**核心规则**：
1. **不可跳越**：任何一方升级推进时，一旦推进会**跨越必打级**（如从 8 级一把升到 11 级会跨过 J），先**停于该必打级先打**，不能通过普通得分直接越过该级。
2. **跳过条件**：要越过必打级，唯一途径是——**当前处于该必打级的一方担任庄家，且对手（闲家）得分 < 75**，此时才可跳过该必打级，跳过时按 9.1 结算表全量推进。
3. **闲家不可借分跳过**：闲家靠抓分（得分 ≥ 80）上台换庄时，**无法跳过必打级**；闲家上台后停在当前必打级上，须后续当庄且对手 < 75 才能继续推进。
4. **打 A 获胜**：处于必打级 **A** 且担任庄家时，若对手得分 **≤ 75**，该方直接**获胜**（完成"转一圈"）。

### 9.3 必打级升级结算表（处于 2 / J / A 时按此结算）

| 闲家得分 | 打 2 | 打 J | 打 A |
|---|---|---|---|
| 0 ~ 70（<75） | 跳过 2，按表全量推进 | 跳过 J，按表全量推进 | **获胜**（≤75） |
| **75** | 升 1 级 | **不升级**（留级） | **获胜**（≤75） |
| 80、85 | 换庄；闲家上台，**停在必打级 2** | 换庄；闲家上台，**停在必打级 J** | 换庄；闲家上台，**停在必打级 A** |
| 90 ~ 200 | 闲家上台，**停在必打级 2** | 闲家上台，**停在必打级 J** | 闲家上台，**停在必打级 A** |

**必打级上的推进说明**：
- 对手得分 < 75 时，庄家**跳过**该必打级，**并按 9.1 结算表推进完整级数**（如打 J、对手 0 分 → 跳过 J 后按表升 8 级），不因在必打级上而削减推进量。
- 对手 = 75 时：打 2 升 1 级；打 J 不升级（留级）；打 A 获胜。
- 对手 ≥ 80 时换庄：闲家上台后**停在当前必打级**（不能借得分跳过），须日后当庄且对手 < 75 才能继续。

### 9.4 自然级

- **触发条件**：当前级别为 **2**，庄家方本局获胜，且闲家得分 **低于 80 分**；本局未发生闲家以 **510k 抄底**。
- **升级效果**：在本局常规升级结算后，庄家方额外升 **1 级**。此效果不改变胜负、换庄或积分结算。
- **触发次数**：每局最多触发一次。
- 条件不满足时不触发自然级；本局有 510k 抄底时，即使闲家得分低于 80 分也不触发。

## 10 换庄顺序

| 情形 | 下一副牌庄家 |
|---|---|
| 庄家方升级（继续坐庄） | 当前庄家的**对家** |
| 闲家上台换庄 | 本副牌庄家的**下家** |

| 翻盘 | 打 J/A 时闲家以该级牌抄底，额外把庄家级数强制降级 |
| 510k | 同花色 5、10、K 组合牌型；主 510k 盖过副 510k |
| 抽筋 | 甩主 510k 时，其他玩家须出最大 3 张主牌 |
| 上天入地 | 510k 为最后一手且最大时，打出方直接获下一局庄权、打 A 对 2 |
| 春天 | 第一局上天入地、打 A 通过，共两局结束；积分按级差×40（480）结算 |
| 拖拉机 | 同花色相邻连对 |
| 必打级 | 等级 2、J、A；不可借普通得分跳越，须当庄且对手 <75 才能跳过 |
| 跳过 | 必打级上当庄且对手 <75 时，推进 1 级通过该必打级 |
| 自然级 | 打 2 时庄家方获胜、闲家低于 80 分且无 510k 抄底，常规结算后额外升 1 级，每局最多一次 |
| 抢定者 | 发牌阶段用一张级牌暗扣定主的玩家，拥有"回头望"特权 |
| 回头望 | 抢定者用当初抢定的级牌最终定主，视为反主阶段最大 |
| 暗反 | 反主全程暗扣，由系统判定对子大小是否违规 |
